Photomosaic

Arrange a set of photos into a grid that, seen from a distance, reproduces a target picture. Each photo goes to one cell, and the Hungarian algorithm finds the arrangement whose colours match best overall. Your photos are read in this browser and never uploaded.

How this works

This is a port of an R script that made photo grids and mosaics with ImageMagick (through the magick package), and it computes what the script computes:

  • Grid. With n photos and a target of shape a (height ÷ width), the grid has ⌊√(n/a)·a⌋ rows and ⌊√(n/a)⌋ columns, so it never has more cells than photos. Extra photos are left out.
  • Cells. The target is scaled to one pixel per cell, each pixel the average of the area it covers.
  • Photos. Each photo is scaled to 200 pixels wide and summarised by its average colour.
  • Cost. Both are turned into hue, saturation, lightness and opacity, and a cell's cost for a photo is the sum of the squared differences. As the script computes them, hue is in degrees and lightness is scaled down by 255, so the match is mostly by hue, then saturation. The CIELAB option compares perceived lightness and colour instead.
  • Assignment. Each cell gets its own photo, so that the total cost over all cells is as small as possible: the linear assignment problem, solved exactly by the Hungarian algorithm. Photos are first shuffled with the seed, as the script shuffles them, which matters only between equal costs.
  • Drawing. Each photo is drawn at the tile width with its own shape, rows as tall as their tallest photo, as the script appends them. Cropping to squares and tinting towards the target are options here, off by default.

On the same photos and seed it gives the R script's summaries, costs and assignment; JPEG photos can differ by a fraction of a colour level, as browsers' decoders differ. Photos larger than 400 pixels wide, and targets larger than 1600 pixels, are first halved in the browser.

The mosaic is also available to scripts and agents: see the API description. The example is Hokusai's Red Fuji and CC0 photographs from Wikimedia Commons (sources).
