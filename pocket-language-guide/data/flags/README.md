The 78 country flags in this directory are the 4:3 SVGs from
[flag-icons](https://github.com/lipis/flag-icons), used under its MIT license
(see LICENSE.txt). They cover the countries in data/registry/regions.csv.

Source revision and SHA-256 hashes are recorded in
scripts/flag-sources.sha256.json. Run `python3 scripts/fetch_flags.py` to fetch
those exact sources, or add `--check` to verify the local copies without network
access. The web offline shell and native app bundle both include the assets.
