# Mattlab Logo Painter · Cardinal Studio

Paint the twenty pieces of the Mattlab mark, develop letter and number studies, and export individual SVG/PNG images or labeled character sheets. The app is a companion to the [MotRPAC alphabet editor](../), with independent geometry and saved projects.

Serve the site root using `python3 -m http.server 4199 --bind 127.0.0.1` and open `/motrpac-alphabet/mattlab/`. There is no build step or runtime dependency. Tests use Node's built-in runner (`npm test`); browser checks use the repository's existing Playwright installation (`npm run test:browser`).

Choose a color and click or drag over pieces. Keyboard-focused pieces support Enter or Space. Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z undo and redo edits; native text-input undo is preserved. Projects autosave locally. **Save project** exports editable JSON; **Open** restores it, including projects saved by the standalone HTML. Switching between the two editors keeps their projects separate. Help retains the original palette, corner-link, zoom, navigation and character-sheet controls.

The JavaScript modules separate color conversion, immutable logo geometry and exports, imported glyph fills and retained punctuation studies, the project/history model, sheet rendering, and the UI controller. [API and CLI](api.md) access shares those implementations. `index.html` and `styles.css` preserve the supplied Cardinal Studio interface; navigation occupies its existing header.

The imported source is the user-supplied `mattlab-logo-painter.html`; its exact SHA-256 and size are recorded in [provenance.json](provenance.json). Its original `cardinal-studio:<geometry>:v2` storage key is retained, with support for its v1 key. Files opened directly from disk have a different storage origin: use Save project in that copy, then Open here to transfer its studies.

Right-click a painted piece to move its linked colour family to the next palette row throughout the current study, preserving each piece’s shade column. Right-clicking a palette row does the same for that row; Shift cycles backward. The selected paint brush stays unchanged. Cycling skips rows already used by other pieces, keeping color groups separate. If every row is in use, it leaves the colors unchanged. Explicitly dragging a row marker onto an occupied row can still combine groups; Undo restores the previous grouping. Middle-click changes only the brush family. Scrolling over the artwork cycles the Paint, Erase and Pick tools in either direction; scrolling elsewhere remains normal page scrolling. Ctrl/Cmd-scroll and pan mode retain browser zoom/navigation behavior. Repeated clicks on a linked piece cycle its three shades, then a transparent blank shade, then back to the first shade, without leaving Paint. Erase makes pieces transparent. The separate background color applies to the canvas, thumbnails, opaque artwork exports and character sheets; outlines automatically turn white on dark backgrounds. Checker previews transparency. Existing white-painted pieces remain opaque white. Older projects with White selected reopen with a fixed white paint brush.

Auto corners copy both fill and palette binding from the ending leg: the two upper tips follow the upper bridge and upper gray leg; the lower tips follow the left red leg and lower gray bridge. Manual corners preserve their exact saved fills.

The gallery dropdown opens on **Logo designs** by default: NV-1, NV-2, and Original (the warm reference scheme using fixed Logo red and Logo gold rows). The two logo rows retain their exact swatches in every palette mode; right-click cycling back restores those colors. Perceptual controls continue to adjust the other rows. All designs use automatic ending-leg corners. The character options in the same dropdown contain the edited character sheets. The latest ASCII sheet supplies 64 visible glyphs; omitted characters retain their existing blank defaults. All twenty face fills are preserved exactly, including opaque white and transparent pieces. Untouched defaults refresh from the imported sheets; edited documents, including deliberately erased studies, are preserved. Imported cells use manual corners so their exact artwork remains intact. Source hashes and effective character coverage are recorded in [edited-glyphs.provenance.json](edited-glyphs.provenance.json). Import another sheet with `python3 scripts/import-glyph-sheets.py /path/to/sheet.svg`; a directory argument imports the original digits/uppercase/lowercase sheets. Single-sheet imports replace only supplied characters and retain provenance for earlier defaults. Edited copies of the earlier warm Original remain in Saved studies. The older gray Original reference and automatic colour-study presets are absent from the ordinary gallery; edited copies remain in **Saved studies** and project exports.

The MotRPAC/Mattlab switch sits at the start of both editor headers and shares the collection’s lightswitch component. Its position and dimensions match across both pages at each screen size. Mouse, touch, Space and Enter activate it; each editor retains its own saved project. On desktop, the palette, painting canvas and character gallery share the full viewport; palette and gallery content scroll independently. Narrow screens keep the normal stacked page.

Character-sheet exports have a **Nonblank only** checkbox, also available as `options.nonblankOnly` through the API and CLI. It skips cells whose twenty fills are all white or transparent, regardless of edit status or outline guides. The choice is saved with the project. SVG and PNG share the same filtering/layout implementation; an entirely blank selection reports an error.
