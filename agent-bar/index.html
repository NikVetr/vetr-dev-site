Agent Bar demo

A simulation with made-up chats: nothing here reads your computer.

About

What you are looking at

Agent Bar shows what your AI coding agents (Claude Code, Codex, GitHub Copilot CLI and Antigravity) are doing, in the GNOME top bar. If several chats share a window, which one just finished? The top bar says, and one click takes you to that exact chat.

This page is a simulation. The desktop, the chats, the windows and every number in them are made up and run in your browser: the projects belong to an imaginary user, Alex, and the agents reply from a script. The top bar and its dropdown copy Agent Bar's real layout, colours and wording, so you can try what clicking does. The real Agent Bar is a GNOME Shell extension with a background service; it is not a web page. Agent Bar on GitHub · 8-minute video tour

Where it runs

Today: GNOME Shell 42 on X11, as in Ubuntu 22.04. GNOME 43 and later, macOS (in the menu bar) and Windows (in the system tray) are planned.

Costs are estimates

Dollar figures are what the recorded tokens would cost at API prices, including cache reads and writes. Subscription billing is separate.

Privacy

  • History indexes only the words people and agents wrote: no tool calls, tool results or reasoning.
  • Hooks record turn events (starts, finishes, questions, approvals and failures), not message text.
  • Only two optional settings reach the network: Read Claude limits asks api.anthropic.com every 10 minutes, and Pull requests asks GitHub through your signed-in gh.

Optional extras

The Queues and Cluster tabs follow the ROTA job scheduler. Without it, Agent Bar hides them.

Using this demo

  • Tour (or T) starts a short guided tour; Esc ends it, and ← → step through it.
  • Each top-bar part is a button: Tab to it and press Enter. Esc closes the dropdown.
  • On a phone, the top bar wraps into rows and the window in front fills the screen; the strip under it switches windows.
  • Scripts and tests can drive the simulation through window.AgentBarDemo (see the site's README).
