# Tour guide poses

The Agent Bar and ROTA demo tours share one set of guide poses. Biscuit, the Italian greyhound, guides the Agent Bar tour, and Pip, the black-and-white cat, guides the ROTA tour. `poseFor()` in `tour-guide.js` picks the pose, and each demo's `guide/manifest.js` maps the pose names to files: `agent-bar/guide/dog-*.svg` and `rota/guide/cat-*.svg`. When the manifest leaves a pose out, the guide shows `idle` instead, so a character can start with `idle` alone.

Reference sheet with the current art: `tmp/agent/demo-helpers/pose-library.png`, regenerated by `node tmp/scripts/pose-sheet.mjs`. Blank canvas: `pose-template.svg`.

## Poses

| Pose | When the tours show it | Characters | Needed |
| --- | --- | --- | --- |
| `idle` | A step with nothing to do, such as ROTA's dashboard explanation. Also stands in for any missing pose. | both | required |
| `point` | A step waits for the visitor to click, type or watch something. The art faces right. Agent Bar mirrors Biscuit when the target is to its left; ROTA never mirrors Pip. | both | recommended |
| `happy` | The visitor has done the step. The tour adds a small hop and moves on after a moment. | both | recommended |
| `leap` | The guide is moving to the next target. One pose is held for the whole move (0.4–0.9 s). The code moves it along an arc and tilts it by up to 12°, so separate take-off and landing poses and a run cycle are not needed. | both | optional |
| `wave` | The first step (hello) and the last (goodbye). | both | optional |

The guide stays put while the visitor drags the panel, so no carried pose is needed. A step that waits on the simulation, such as ROTA's lease running out, uses `point` towards what to watch, so no thinking pose is needed either. Under reduced motion the guide jumps straight to its next place in that step's resting pose, and `leap` is never shown.

## Asset spec

- **Format.** SVG is preferred. Keep it self-contained: no external images, fonts or scripts, and text converted to paths. Transparent PNG or WebP at 480 × 480 px also works.
- **Canvas.** Square: `viewBox="0 0 240 240"` (or 480 × 480 px). Every pose of a character uses the same canvas and scale, so switching poses never moves or resizes the guide.
- **Anchor.** Feet, or a sitting cat's base, rest on the ground line at y = 228, centred on x = 120. Keep the art inside the box from 12 to 228 across and 12 to 236 down. `leap` may lift off the line but keeps the same body size.
- **Display size.** Biscuit appears at 96 CSS px and Pip at 72 CSS px, so one canvas unit is 0.4 px and 0.3 px. Draw details at least 6 units across, or they disappear on screen.
- **Facing.** Biscuit is drawn in profile with the nose to the right. Agent Bar flips Biscuit (`scaleX(-1)`) to face a target on the left, so the markings must still look right mirrored (`mirror: true` in its manifest; set it to `false` to stop the flipping). Pip faces the viewer, with gestures towards the right. ROTA never mirrors Pip, because the black patch covers only one eye.
- **Placement.** Biscuit stands beside or below the target, nose towards it. Pip sits on the top edge of the target window, with the bottom 22 px of its 72 px box over the title bar, or sits left of a small target such as the cable button.
- **Light and dark.** Draw without an outline. Both pages add a soft drop shadow, and ROTA also adds a 1 px light rim so black fur stays visible on the near-black window bars. Use charcoal (`#25272c`) rather than pure black for dark fur, so lines inside it still show. Check each pose on white and on the window bars: `#151b25` in ROTA and `#303030` in Agent Bar.
- **Names.** `<character>-<pose>.svg`, for example `dog-idle.svg` or `cat-point.svg`, in the demo's `guide/` folder. Replacing a file under the same name needs no code change. For another name or format, edit the manifest.
- **Size.** At most 30 KB per SVG pose or 80 KB per PNG, and 150 KB per character. Every pose loads with the page.
