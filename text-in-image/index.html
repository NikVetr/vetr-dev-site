    Using Text in Image

    Choose a picture and paste the text you want to fit inside it, or load the example. Adjust the palette, text size and layout settings, then run the layout and download the result. The result uses the picture’s colours; the API link in the footer describes the same inputs for scripts.

    Load example and Clear offer Undo until you next edit an input. Use Result ↓ to reach the preview, and open Rendering details for the palette and fitting diagnostics.
