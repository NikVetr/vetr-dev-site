# CEO salary benchmark

This directory contains a validated public-record CEO compensation benchmark for Rethink Priorities and a standalone vanilla HTML/CSS/JavaScript explorer intended for `https://vetr.dev/ceo-salary-benchmark/`. The route is deliberately absent from the vetr.dev homepage project list.

## Web application

`index.html`, `style.css`, `app.js`, and generated `app-data.js` form the static GitHub Pages application. The desktop layout uses a settings column, a central weighted histogram and quantile view, and a sortable/filterable evidence table. Narrow layouts stack these regions.

The app keeps incumbent Form 990 evidence separate from recruitment postings by default. Incumbent users can switch among validated Schedule J base compensation, Part VII cash/W-2 proxy, and filing-total proxy. A deliberately labeled combined view pools incumbent Schedule J base salary with recruitment-posting midpoint, both in July 2026 USD. It does not pool all three filing measures because that would duplicate correlated observations from the same executive and falsely inflate precision. The combined view retains evidence type as a filter, table column, scatterplot color variable, and optional equal-stream weighting rule.

The default view is an equally weighted lognormal summary with its density overlaid on the histogram; empirical and gamma summaries are explicit alternatives. The initial 2–200 bin control is calibrated to make organization blocks approximately square at the current viewport. The histogram always shows exact-observation rug marks, reserves headroom above the tallest mark, and labels both axes. The header can switch to a scatterplot with salary on the vertical axis and expenses, revenue, staff, comparability score, or evidence year on the horizontal axis. Points can be colored by tier, topic/model, EA relationship, evidence stream, job-title group, or structure. Optional weighted bivariate-normal covariance ellipses show approximately 50%, 80%, and 95% data contours; they are descriptive data ellipses, not causal or parameter-confidence intervals.

Sample presets are described in place: the validated primary set follows the source and role-structure audit; the structurally clean subset additionally removes flagged structures; Tier A / strict-primary is the narrowest peer definition; and every observed salary includes broader sensitivity rows. Base-weighting choices use visible table metadata: equal observations, equal evidence streams, match/comparability score, expense similarity, staff similarity, evidence recency, tier, EA relationship, or comparability × expense similarity. Organization-specific multipliers and row inclusion toggles remain available. Rows without the active compensation measure are hidden by default and can be exposed for auditing, with unavailable inclusion controls disabled. Each chart mark focuses the corresponding evidence row.

Organization and source-native job-title fields are separate. The title filter groups exact, indented source titles beneath clickable CEO, Executive Director, President, Co-leadership, Other, and Not-reported headings rather than replacing their displayed wording. A filter whose values are all checked offers “Deselect all”; partial or empty selections offer “Select all.” Evidence type, title, tier, topic, location, EA relationship, and organizational-structure columns use exact-value checkbox menus that support multi-selection. Salary and Expenses have matching column-filter buttons that reveal two-ended range controls only while their popovers are open; the expense control uses a logarithmic scale. Categorical and numeric filters update the table, chart, fitted distribution, statistics, and quantiles from the same observation subset. The global table search and invariant work-model column are omitted. Every sortable column shows a persistent sort affordance and exposes its active direction accessibly, while the compact Tier column truncates long labels with their full value available on hover.

The table also exposes staff count and evidence year. Preserved Form 990 website declarations supply organization-homepage links for 121 incumbent peers. Hovering or focusing the organization-name text—not unused space elsewhere in its cell—opens a card that combines local benchmark context with an optional live, explicitly unverified Wikipedia search preview; the benchmark never stores that preview as analytical data. Quantiles can be shown as quintiles, deciles, all percentiles, or user-entered percentile levels, and the panel identifies whether they come from empirical weighted ranks or a fitted distribution. Hovering or focusing a quantile projects it onto the chart. The interface uses the Rethink Priorities blue palette and the local Aspekta variable font. Help tooltips use collision-aware fixed positioning so they remain inside the viewport.

Source previews display the exact evidence fields used for the selected measure. Third-party links open the public host, while `evidence/original/` contains compactly published copies of the original XML, HTML, or PDF artifacts referenced by app observations. `scripts/build_app_data.py` rebuilds both the app dataset and this publishable source subset from the validated benchmark deliverables.

## Analytical package

`benchmark/` contains the protocol chain, frozen peer universes, original analysis, independent validation, source manifests, and acquisition utilities. Stable source IDs connect analytical rows to source-native files and retrieval metadata. All 349 required source records are locally preserved: 135 IRS XML returns, 32 job-ad records, 174 supporting web sources, seven frozen inputs, and one documented search record.

Independent parsing found that the original analysis omitted Schedule J base compensation and misstated the Center for AI Safety Part VII amounts. The app therefore uses `validated_form990_compensation.csv` and `validated_job_ad_compensation.csv`, not the uncorrected original evidence columns. All 15 primary quantitative job-ad ranges now verify locally. The Marine Science Institute exclusion remains unchanged, but its recovered source corrects the role title to Executive Director.

The strict `source_complete` packager remains fail-closed because it requires the original expected fields to agree with every source as well as requiring all files to exist. Its remaining failures are extraction/data-contract findings, not remote-retrieval gaps.

## Reproduction and testing

- `python3 scripts/build_app_data.py` rebuilds the static app data and publishable evidence files.
- `npm run serve` serves the route locally on port 4173.
- `npm test` starts a local server and runs focused Playwright checks for histogram and density rendering, distribution switching, the combined evidence stream, scatter axes/colors/covariance contours, metadata-driven weighting, sample descriptions, grouped title filtering, select-all/deselect-all state, y-axis headroom, row inclusion, unavailable observations, filter-to-chart synchronization, two-ended numeric filters, percentile provenance, source and organization previews, H-CAP and Center for AI Safety corrections, viewport-safe tooltips, evidence-stream switching, and responsive layout.
- The benchmark's independent audits and source validators remain under `benchmark/scripts/`.

The app is decision support for board deliberation, not a population salary estimator or a substitute for a formal compensation-reasonableness process.
