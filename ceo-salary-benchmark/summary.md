# CEO salary benchmark

This directory contains a validated public-record CEO compensation benchmark for Rethink Priorities and a standalone vanilla HTML/CSS/JavaScript explorer intended for `https://vetr.dev/ceo-salary-benchmark/`. The route is deliberately absent from the vetr.dev homepage project list.

## Web application

`index.html`, `style.css`, `app.js`, and generated `app-data.js` form the static GitHub Pages application. The desktop layout uses a settings column, a central weighted histogram and quantile view, and a sortable/filterable evidence table. Narrow layouts stack these regions.

The app keeps incumbent Form 990 evidence separate from recruitment postings by default. Incumbent users can switch among validated Schedule J base compensation, Part VII cash/W-2 proxy, and filing-total proxy. A deliberately labeled combined view pools incumbent Schedule J base salary with recruitment-posting midpoint, both in July 2026 USD. It does not pool all three filing measures because that would duplicate correlated observations from the same executive and falsely inflate precision. The combined view retains evidence type as a filter, table column, scatterplot color variable, and optional equal-stream weighting rule.

The default view is an equally weighted lognormal summary with its density overlaid on the histogram; empirical and gamma summaries are explicit alternatives. The initial 2–200 bin control sits directly below the histogram/scatterplot selector and is calibrated to make organization blocks approximately square at the current viewport. The histogram always shows exact-observation rug marks, reserves headroom above the tallest mark, and labels both axes. Short horizontal-axis tick marks are omitted so they do not resemble rug observations; hovering or focusing a histogram block emphasizes its exact corresponding rug mark. The mark tooltip identifies the organization and role, presents compensation prominently, and reports the bin or scatter coordinate, advertised range where applicable, peer tier, evidence year and type, match score, effective weight, and active color category. Sidebar controls switch between histogram and scatterplot and apply a shared color field—tier, topic/model, EA relationship, evidence stream, job-title group, or structure—to either view. For color encoding, the recruitment taxonomy is consolidated into readable Tier A / primary, Tier B / secondary, and Tier C / expanded legend groups; exact source-native subtiers remain visible in the table and tooltip. Visible descriptions and collision-aware help explain the category codings, including the tier hierarchy.

The scatterplot places salary on the vertical axis and expenses, revenue, staff, comparability score, or evidence year on the horizontal axis. Optional weighted bivariate-normal covariance ellipses show approximately 50%, 80%, and 95% data contours; they are descriptive data ellipses, not causal or parameter-confidence intervals.

Sample presets are described in place: the validated primary set follows the source and role-structure audit; the structurally clean subset additionally removes flagged structures; Tier A / strict-primary is the narrowest peer definition; and every observed salary includes broader sensitivity rows. Weighting is component-based: users may select any combination of match score, expense similarity, staff similarity, recency, tier, EA relationship, evidence stream, topic/model, title group, structure, and equal-stream balancing. The component checklist remains sticky at the top of the desktop settings scroller while its detailed controls pass beneath it. Active component multipliers are multiplied together before the editable row multiplier. Every discrete component opens with documented suggested category values: 1.00 is the reference, lower values moderately downweight broader tiers, weaker EA or topical fit, advertised rather than realized compensation, less directly comparable titles, and structurally dissimilar organizations. Every category row has a keyboard-accessible, collision-aware explainer grounded in the frozen non-pay protocol: tier explainers state the score, function, scale, role, and structural rules; EA explainers distinguish explicit EA-core, EA-adjacent/recommended-cause, functional-only, and uncoded relationships; structure explainers decode the source-derived legal, governance, and reporting arrangements. Uncoded categories remain neutral where penalizing missing metadata would be misleading. Suggested values are initialized on first activation, remain directly editable when a component is toggled off and on, and return to their defaults only with the global reset. Each continuous component's compact response curve follows that component's own target/bandwidth or half-life controls, so adjustments and their implications remain visually grouped. Every response plot has four ticks per axis and explicit variable and multiplier labels. Expense and staff plots include a directly labeled RP reference line at $7.5M and 57 FTE; if the user changes the weighting target, the fixed RP marker remains visible separately. Organization-specific multipliers and row inclusion toggles remain available. Rows without the active compensation measure are hidden by default and can be exposed for auditing, with unavailable inclusion controls disabled. Each chart mark focuses the corresponding evidence row.

The RP size defaults are source-backed rather than guessed. Expense similarity targets RP's published $7.5 million 2026 core budget, which excludes the expenses of fiscally sponsored Special Projects. Staff similarity targets RP's published 57 full-time equivalents at year-end 2024 (61 permanent staff). These fixed references float in a dedicated strip above the evidence table, aligning with the Expenses and Staff columns as the table scrolls rather than occupying the sortable column headers. The interface links both the live and cached RP sources and documents the 2024 Form 990's $20,378,936 consolidated expense total as an optional sensitivity reference. That filing includes Special Projects and reports zero employees, so its expense and headcount fields are not treated as the primary core-operating targets. The page favicon is a local copy of the icon declared by the official RP website.

Organization and source-native job-title fields are separate. The title filter groups exact, indented source titles beneath clickable CEO, Executive Director, President, Co-leadership, Other, and Not-reported headings rather than replacing their displayed wording. A filter whose values are all checked offers “Deselect all”; partial or empty selections offer “Select all.” Evidence type, title, tier, topic, location, EA relationship, and organizational-structure columns use exact-value checkbox menus that support multi-selection. Salary and Expenses have matching column-filter buttons that reveal two-ended range controls only while their popovers are open; the expense control uses a logarithmic scale. Categorical and numeric filters update the table, chart, fitted distribution, statistics, and quantiles from the same observation subset. The global table search and invariant work-model column are omitted. The table initially sorts from the narrowest peer tier to broader, sensitivity, and excluded tiers, with organization name as a stable secondary key. Every sortable column shows a persistent sort affordance and exposes its active direction accessibly, while the compact Tier column truncates long labels with their full value available on hover.

The table also exposes staff count and evidence year. Preserved Form 990 website declarations supply organization-homepage links for 121 incumbent peers. Hovering or focusing the organization-name text—not unused space elsewhere in its cell—opens a card that combines local benchmark context with an optional live, explicitly unverified Wikipedia search preview; the benchmark never stores that preview as analytical data. Quantiles can be shown as quintiles, deciles, all percentiles, or user-entered percentile levels, and the panel identifies whether they come from empirical weighted ranks or a fitted distribution. Ordinal suffixes in percentile labels are superscripted. Hovering or focusing a quantile projects it onto the chart. The interface uses the Rethink Priorities blue palette and the local Aspekta variable font. Help tooltips use collision-aware fixed positioning so they remain inside the viewport. Scrollable panels reserve a stable internal gutter and use narrow, semi-transparent scroll thumbs, preventing scrollbar appearance from shifting panel contents.

Source previews display the exact evidence fields used for the selected measure. Third-party links open the public host, while `evidence/original/` contains compactly published copies of the original XML, HTML, or PDF artifacts referenced by app observations. `scripts/build_app_data.py` rebuilds both the app dataset and this publishable source subset from the validated benchmark deliverables.

## Analytical package

`benchmark/` contains the protocol chain, frozen peer universes, original analysis, independent validation, source manifests, and acquisition utilities. Stable source IDs connect analytical rows to source-native files and retrieval metadata. All 349 required source records are locally preserved: 135 IRS XML returns, 32 job-ad records, 174 supporting web sources, seven frozen inputs, and one documented search record.

Independent parsing found that the original analysis omitted Schedule J base compensation and misstated the Center for AI Safety Part VII amounts. The app therefore uses `validated_form990_compensation.csv` and `validated_job_ad_compensation.csv`, not the uncorrected original evidence columns. All 15 primary quantitative job-ad ranges now verify locally. The Marine Science Institute exclusion remains unchanged, but its recovered source corrects the role title to Executive Director.

The strict `source_complete` packager remains fail-closed because it requires the original expected fields to agree with every source as well as requiring all files to exist. Its remaining failures are extraction/data-contract findings, not remote-retrieval gaps.

## Reproduction and testing

- `python3 scripts/build_app_data.py` rebuilds the static app data and publishable evidence files.
- `npm run serve` serves the route locally on port 4173.
- `npm test` starts a local server and runs focused Playwright checks for histogram and density rendering, linked block/rug highlighting, shared categorical coloring, distribution switching, the combined evidence stream, scatter axes/colors/covariance contours, simultaneous continuous and editable discrete weighting, weight-response curves, sample descriptions, grouped title filtering, select-all/deselect-all state, y-axis headroom, row inclusion, unavailable observations, filter-to-chart synchronization, two-ended numeric filters, percentile provenance, source and organization previews, H-CAP and Center for AI Safety corrections, viewport-safe tooltips, evidence-stream switching, and responsive layout.
- The benchmark's independent audits and source validators remain under `benchmark/scripts/`.

The app is decision support for board deliberation, not a population salary estimator or a substitute for a formal compensation-reasonableness process.
