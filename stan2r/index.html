How to use the result

The explorer uses Stan’s type checker and a supported generative subset: scalar/vector priors, deterministic transforms, and sampled data. It reports unsupported constructs explicitly. Select a node to adjust literal prior arguments or fix a parameter, including hyperparameters. These exploration changes leave the Stan source untouched; LaTeX and Python exports include them.

Prior predictive histograms are independent Monte Carlo draws, not posterior estimates. No analytic approximation or MCMC fitting is performed. Arrow dependencies include shape and bound inputs; a plate marks repeated elements. Fixing a node is an intervention in the generative graph, not conditioning a fitted model.

For the R converter, define dat in R, then run the downloaded script. Its out list contains the model’s top-level variables. Density modes return ordinary densities or probabilities, not log densities. The R converter supports more Stan constructs than the explorer.

The first successful conversion downloads the R runtime. Later conversions reuse it. Internet access is needed for this initial download. Stan2R reports unsupported constructs instead of silently omitting them. Provide a self-contained Stan model; external #include files are not supported here.
