Data & posterior draws JSON

Draw numbers start at 1. Use CmdStan column names such as theta[1]. The output embeds the selected parameter draw; it reads observed data from an R list named dat.

How to use the result

Define dat in R, then run the downloaded script. Its out list contains the model’s top-level variables. Density modes return ordinary densities or probabilities, not log densities. This tool translates a model; it does not fit it.

The first successful conversion downloads the R runtime. Later conversions reuse it. Internet access is needed for this initial download. Stan2R reports unsupported constructs instead of silently omitting them. Provide a self-contained Stan model; external #include files are not supported here.
