Message Collage

Turn a set of short messages, such as farewell or thank-you notes, into one dense card, each message in its own font, size and colour. Your messages never leave this browser.

Card size and layout

Gaps are fractions of each message's capital height. Fill sets one scale for all text: at 0.7, the messages set on single lines would cover 0.7² = 49% of the card.

Colours

Each message takes a colour no nearby message has, as far as the palette allows.

How this works

Each message draws a font family and a style at random, and a size: a number between the smallest and largest relative size, divided by the average of all the messages' numbers. One scale then sets every message's text so that, set on single lines, the messages would cover fill² of the card.

The messages are then placed in a shuffled order, line by line, on a grid of small cells. A message's first line takes the top-left-most free block that its first word fits, and as many words as fit there. Each next line starts on the row just below, within the span of the line above, and lines up with its left or right edge when the cells allow. If a message runs into others, it starts again somewhere else. When the messages need more room than the card has, the card grows downward. A line ending close to the right edge is moved flush right.

Colours go to the messages in order: first colours not yet used, then colours whose nearest message of the same colour is farthest away, drawn at random with odds that favour distance.

This is tried for as many layouts as you ask, each with its own fonts, sizes and colours (the order stays the same), and the layout with the fewest empty cells is kept.

The seed fixes every random choice, so the same messages and settings always give the same card. This is a port of an R program, and gives exactly the R version's card for the same fonts, settings and seed. The tool is also available to scripts and agents: see the API description.
