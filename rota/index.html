What's real here

Simulated

Nothing runs on a cluster: a model of ROTA's coordinator runs in this page, one tick per simulated second, ten times faster than real time by default. It is a JavaScript port of the scheduler's allocation and start pacing, the same port that drives the explainer video, so priorities, per-host budgets, round-robin turns and paced starts behave as they do in the real coordinator. Leases, dependencies, pauses, failure holds and share interruptions follow the scheduler's rules.

Simplified: plans reach hosts at once; there is no shared-I/O admission (the example pool turns it off); live capacity equals each host's budget; memory is charged at the declared amount. Job runtimes are made up, the files are read-only, and a few real commands (setup, rota kill, rota control, memory calibration) answer with a note instead.

Faithful: the command output uses the real scripts' messages and key=value records, and the dashboard is a port of ROTA's own pane renderers, checked against them. The hosts and paths are those of the public example inventory, examples/cluster.json.

ROTA's real limits

  • macOS and Linux only.
  • A shared drive, mounted at the same path on every host, plus passwordless SSH from the coordinator.
  • Each job runs on one host: no MPI and no multi-node jobs. For many users, isolation or dozens of hosts, Slurm, Flux or HTCondor fit better.
  • Priority never preempts: a higher priority only gets the next free slots.
  • An expired lease never kills a job, and nothing is re-run automatically. You audit, then retry.
  • Backfill, GPU units and holding work while a machine's owner is at the keyboard are opt-in and off by default.

Using this page

Type into the storage and worker windows as you would in a terminal: Tab completes commands, options and paths, ↑ and ↓ recall history, and Ctrl+L clears. Commands (Ctrl+K) lists commands to try with this pool's paths filled in. On a phone, the windows become tabs, and picking a command puts it in the shell for you to run. Scripts can drive the page through window.RotaDemo (see the folder's README).
